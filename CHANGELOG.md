## [1.0.0] - 2025-01-01

### Added
- Config-driven README generation from `readmeforge.yml`
- Five built-in templates: minimal, standard, full, library, cli
- Auto-generated badge shields
- `init`, `generate`, `validate`, `templates` commands
- Mustache template engine support
- YAML and JSON config format support
